基于 erpnext/ 代码库 doctype 定义自动提取 · 核心业务域实体与关键外键关系

统计概览

  • • 业务域：9 个（基础配置/库存/合作伙伴/财务/项目/销售/采购/制造/资产等）
  • • 核心主数据：20+ 实体
  • • 交易单据：15+ 核心单据
  • • 子表（行项目）：10+
  • • 台账/辅助实体：10+

核心业务流程

  • • 销售：Lead → Opportunity → Quotation → SO → DN → SI
  • • 采购：MR → PO → PR → PI
  • • 库存：Stock Entry / Stock Ledger Entry / Bin
  • • 财务：Payment Entry / Journal Entry / GL Entry
  • • 制造：BOM → Work Order → Stock Entry (生产入库)

设计特点

  • • Frappe 框架：Link 字段 = 外键；Table 字段 = 子表（一对多）
  • • 动态 Link：party_type/voucher_type 等实现多态关系
  • • 单据转换：行子表通过前序单据 Link 字段回指，表头不直接关联
  • • 退货：is_return + return_against 自引用
  • • 修订：amended_from 自引用实现版本链

跨公司 / 多公司

  • • Sales Order ↔ Purchase Order（互指）
  • • Delivery Note ↔ Purchase Receipt（互指）
  • • Sales Invoice ↔ Purchase Invoice（互指）
  • • Journal Entry ↔ Journal Entry（互指）
  • • Customer/Supplier 可代表公司（represents_company）

树形 / 层级实体

  • • Company、Account、Warehouse、Item Group
  • • Cost Center、Territory、Customer Group
  • • Task（parent_task）、Batch（parent_batch）
  • • Location（资产位置）、Department
  • • Employee（reports_to 自引用）

重要台账实体

  • • GL Entry：总账分录，所有财务单据的落点
  • • Stock Ledger Entry：库存台账分录
  • • Bin：物料-仓库 库存余额
  • • Item Price：物料价格表记录
  • • Serial and Batch Bundle：新序列号/批次模型
